End of Support

SQL Server 2016 Is Now Out of Support

SQL Server 2016 reached end of support on July 14, 2026. Without Extended Security Updates, Microsoft no longer provides security updates, leaving workloads exposed to unpatched vulnerabilities.

End of Support Date

July 14, 2026

Extended Security Updates are available through July 17, 2029

Support Has Ended: Know What ESUs Cover

RatingWhat It Means
CriticalESUs provide MSRC-rated Critical security updates if and when released. Latest service pack and eligible licensing are required.
Limited scopeESUs do not provide new features or general nonsecurity fixes. Technical support is limited to ESU-related issues; subscription alone does not establish compliance.

Savings Plan for Databases

A database savings plan commits a fixed hourly spend for one or three years across eligible services and regions within its scope. Unused hourly commitment expires, excess usage is pay-as-you-go, and purchases cannot be canceled or refunded. SQL Server VM/Arc hourly licenses can consume commitment at their normal pay-as-you-go price. Check eligibility and terms before buying.

Top 5 Reasons to Upgrade to SQL Server 2025

Upgrade for a supported lifecycle and modern capabilities. Assess edition, OS, drivers, deprecated features, compatibility levels, and vendor certification; rehearse restore and rollback before production cutover.

Supported Security Lifecycle

Move to a supported release, apply current updates, and validate least privilege and encryption. Cross-product CVE totals are not a comparable security benchmark.

AI & Vector Capabilities

Evaluate native vector features for your workload. Feature availability and preview status vary; external embedding or model endpoints can add cost, identity, and data-handling requirements.

Modern Developer Workflows

Streamlined tooling to build modern data applications faster than ever.

Analytics via Fabric

Use supported integration paths with explicit permissions, replication monitoring, and freshness targets. Analytics copies do not replace transactional backups.

Flexible Deployment

Choose Azure or on-premises while checking edition, OS, hardware, and feature support. Deployment choices do not have identical capabilities.

FAQ

Frequently Asked Questions

What happens after July 14, 2026? ▼
SQL Server 2016 is out of support. ESUs provide Critical security updates when available, but do not include new features, nonsecurity updates, or general technical support. ESUs are a temporary bridge while you migrate or upgrade.
Are ESUs free on Azure VMs for SQL 2016? ▼
No. SQL Server 2016 ESUs are paid across deployment environments, including Azure VMs. Azure Arc provides pay-as-you-go ESU subscriptions; verify current pricing and eligibility for your licensing agreement.
What is the Savings Plan for Databases? ▼
A one- or three-year hourly spend commitment for eligible database usage. Microsoft advertises up to 35% savings, varying by meter and term. Unused hourly commitment expires, excess usage is pay-as-you-go, and purchases cannot be canceled or refunded. Compare with reservations using observed usage and a dated quote; not every cost component receives a discount.
What is Azure Hybrid Benefit? ▼
Azure Hybrid Benefit applies qualifying SQL Server licenses with active Software Assurance or eligible subscriptions to supported Azure SQL services. Verify core conversion, allocation, and dual-use terms. Reservations reduce eligible infrastructure charges; neither makes the entire service free.
Can I use Azure Arc for ESU if I'm not in Azure? ▼
Yes! Azure Arc lets you enroll and purchase ESUs directly in the Azure Portal for on-premises and multi-cloud servers. You get pay-as-you-go billing, centralized visibility, and can stop charges immediately when no longer needed.
What is Next-Gen General Purpose? ▼
Next-gen GP upgrades General Purpose storage to Elastic SAN, supporting up to 500 databases and 32 TB per instance. The baseline price is comparable to GP, but extra IOPS and memory are billed separately. Ignite 2026 announced GA zone redundancy and flexible memory for zone-redundant Premium-series instances in supported regions. Benchmark workload performance rather than assuming a fixed multiplier.
